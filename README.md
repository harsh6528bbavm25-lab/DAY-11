## 📖 Description
This project demonstrates the use of **Canva Magic Studio and AI-assisted design tools** to create a professional aviation mini-campaign.

The campaign focuses on helping passengers prepare for air travel and encouraging them to verify important travel information through official airline and airport channels.

## 🎯 Campaign Objectives
- Promote responsible travel-information checking.
- Encourage passengers to use official sources.
- Create consistent aviation-themed visual content.
- Apply a professional brand identity across multiple formats.
- Demonstrate responsible use of AI-generated visuals.
